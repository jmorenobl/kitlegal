# SC-008 medido en T011 — diferencial y acotado a las rutas de fixtures

Obligación 7 del plan (quickstart 1 y 7). La medida es **diferencial**: se compara la salida de
`git status --porcelain` restringida a las rutas de fixtures **antes** y **después** de `make ci`, y no se
exige un `git status` vacío, porque el árbol de trabajo lleva los artefactos de `specs/` sin seguimiento y
`make ci` escribe `coverage.out`, que `.gitignore` ya excluye.

## Cómo se midió

```
git status --porcelain -- ':(glob)**/testdata/**' ':(glob)testdata/**'   # antes
make ci
git status --porcelain -- ':(glob)**/testdata/**' ':(glob)testdata/**'   # después
```

Las órdenes se ejecutaron con `rtk proxy` para que ninguna capa reescribiera la salida que se compara.

## Resultado

| Medida | Antes | Después | Diferencia |
|---|---|---|---|
| Rutas de fixtures (`**/testdata/**`, `testdata/**`) | 0 entradas | 0 entradas | ninguna |
| Árbol entero (`git status --porcelain`) | 11 entradas | 11 entradas | ninguna |
| `*.json.parcial` o `grabacion-*` sueltos en el árbol | ninguno | ninguno | ninguna |

`make ci` terminó con código 0 («ci: todos los controles en verde»). Ningún fichero versionado quedó
modificado y no apareció ninguna grabación: en este hito la raíz de grabación solo existe dentro de un
`t.TempDir()`, y sin la variable de entorno la cadena del cliente ni siquiera lleva el escalón que grabaría
(FR-041).

El único directorio `testdata/` del repositorio hoy es `internal/app/testdata`, de H1;
`internal/httpx/testdata/reproduccion/prueba/` lo aporta T012, que es `[datos]`. La medida ya cubre las dos
rutas, así que vale igual cuando ese árbol exista.

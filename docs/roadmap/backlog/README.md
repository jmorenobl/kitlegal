# Backlog

Candidatos agrupados por tema. Ninguno tiene número ni especificación hasta que pasa a `todo/`, y lo que decide que entre es `docs/USO.md` (§6). Entre grupos no hay dependencias salvo una: «fiscalizar y vigilar» necesita las fuentes de «Transparencia y fiscalización municipal» y el grafo, y es el único que no puede adelantarse. Cada candidato conserva los controles que tenía cuando era hito numerado (ADR 0013, tabla de correspondencia).

Cada grupo es un fichero, y las materias y las verticales, un directorio con un fichero por materia o vertical. Los hitos de `transparencia-y-fiscalizacion/` conservan el número que tenían cuando eran la fase 3.
